# Правила для агентов

- Отвечай пользователю по-русски, если он явно не попросил другой язык.
- Рабочие файлы проекта находятся в корне: `app.py` — настольное приложение PyQt6 и локальная SQLite-база; `server.py` — Flask API и облачная SQLite-база; `templates/index.html` — веб-интерфейс; `tests/test_shift_sync.py` — тесты синхронизации.
- Считай `_backup_*` и `_runtime_*` копиями, а не источником истины. Работай с ними только если пользователь прямо указал соответствующую копию.

## Проверки и данные

- Для набора тестов используй `python -m unittest discover -s tests -p "test_*.py"`. Тестам, импортирующим настольный `app.py`, нужен PyQt6; он не указан в `requirements.txt`.
- Не направляй проверки на `smart_report.db` или `cloud_database.db`. Синхронизацию проверяй только в изолированном локальном окружении с отдельными тестовыми базами и локальным сервером.
- Не запускай `app.py` как способ проверить синхронизацию: настольный клиент настроен на внешний сервер. Не раскрывай и не копируй секреты из исходников; тестовые секреты задавай отдельно.

## Настройка голоса VS Code

- `accessibility.voice.speechLanguage` — настройка распознавания речи VS Code, а не параметр SmartReport. Не пытайся менять ее через `app.py`, `server.py` или веб-интерфейс.
- Если пользователь просит настроить эту опцию, уточни нужный язык распознавания и область действия настройки (профиль VS Code или workspace); проверь допустимое значение настройки и не создавай `.vscode/settings.json` без необходимости.
- Не смешивай язык распознавания речи с языком ответа ассистента или переводом данных приложения.
