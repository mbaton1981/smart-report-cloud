# Правила для агентов

- Отвечай пользователю по-русски, если он явно не попросил другой язык.
- Этот клон (`smart-report-cloud-ob-worktree`, ветка `main`) — **основной checkout** для правок,
  тестов и выпусков. `app.py` — настольное приложение PyQt6; `server.py` — Flask API.
- Закреплённые пути: установка `%LOCALAPPDATA%\Programs\SmartReport-<версия>` (текущая 1.0.70,
  проверенный откат 1.0.69); профиль рабочих данных `C:\Users\mbato\AppData\Local\SmartReport-1.0.9`;
  запуск — существующие ярлыки «SmartReport» (рабочий стол и «Пуск») через
  `launch_existing_profile.ps1`; выпуск — `packaging\build_installer.ps1` из чистого дерева,
  артефакты в OneDrive `..\installer\`. Render: Auto-Deploy отключён, деплой вручную и только
  при серверных изменениях.
- Корень workspace (`..\`) — старая копия кода и рабочие данные; код там не править.
- Считай `_backup_*` и `_runtime_*` копиями, а не источником истины. Работай с ними только если пользователь прямо указал соответствующую копию.
- Не запускай две сессии агента на этом репозитории одновременно.
- В рамках порученной задачи пользователь разрешает самостоятельно читать и исправлять код,
  выполнять необходимые проверки, собирать и устанавливать SmartReport, обновлять существующие
  ярлыки с сохранением рабочего профиля, публиковать изменения в `origin/main`, открывать
  приложение и проверять интерфейс. Разрешение сохраняется между шагами и сессиями.
  Не запрашивай повторное согласие на уже порученные действия по собственной инициативе;
  если подтверждение обязательно по правилам инструмента, укажи конкретный источник требования.
- Это разрешение не включает произвольное удаление рабочих данных, изменение финансовых записей,
  отправку писем, изменение настроек безопасности и новые действия вне порученной задачи.
- При технической ошибке управления перечитай состояние окна и используй поддерживаемые
  инструментом действия. Явный запрет политики не обходи; продолжай независимую доступную работу.
  Если нужно участие пользователя, попроси одно простое действие без команд, путей и правки ярлыков.

## Проверки и данные

- Для набора тестов используй `python -m unittest discover -s tests -p "test_*.py"`. Тестам, импортирующим настольный `app.py`, нужен PyQt6; он не указан в `requirements.txt`.
- Не направляй проверки на `smart_report.db` или `cloud_database.db`. Синхронизацию проверяй только в изолированном локальном окружении с отдельными тестовыми базами и локальным сервером.
- Не запускай `app.py` как способ проверить синхронизацию: настольный клиент настроен на внешний сервер. Не раскрывай и не копируй секреты из исходников; тестовые секреты задавай отдельно.

## Настройка голоса VS Code

- `accessibility.voice.speechLanguage` — настройка распознавания речи VS Code, а не параметр SmartReport. Не пытайся менять ее через `app.py`, `server.py` или веб-интерфейс.
- Если пользователь просит настроить эту опцию, уточни нужный язык распознавания и область действия настройки (профиль VS Code или workspace); проверь допустимое значение настройки и не создавай `.vscode/settings.json` без необходимости.
- Не смешивай язык распознавания речи с языком ответа ассистента или переводом данных приложения.
