## Что сделано
- Распознавание счетов: все страницы PDF, встроенный текст + локальный OCR, координатный разбор подписей и значений, повёрнутые страницы, продавец/покупатель, номера заказов и проектов.
- Финансы: `Decimal`, net + НДС + округление = сумма к оплате; неизвестные НДС/валюта не подставляются; обратное начисление требует ручной проверки; предоплата (AJ) — только черновик.
- Распределение по net: объекты по стабильным ID, расходы компании без объекта; счётчик распределения считает только выбранный объект/компанию (исправлен дефект UI).
- Срок оплаты: явный / рассчитанный / ручной / неоднозначный, с источником и проверкой.
- Синхронизация: долговечная очередь, `client_id`, CAS по `sync_version`, вложения с SHA256, строгая проверка ACK, повторы после потери ответа.
- BAUHAUS 405139854 принят с первого прохода (9/9); это проверка распознавания, не сертификация UI.
- Релизная подготовка: сервер добавляет колонки срока оплаты в существующую БД (аддитивно); перестройка схемы net-распределений — только при `SMARTREPORT_UPGRADE_NET_SCHEMA=1` после автоматической резервной копии при старте.
