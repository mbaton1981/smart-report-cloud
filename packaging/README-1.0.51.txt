SmartReport 1.0.51 — Windows x64

SmartReport-Setup-1.0.51.exe is the installer for the current Windows user.
SmartReport-1.0.51-build-win64.zip contains the same application files in a
SmartReport folder.

For a new installation, run the installer and use the shortcut it creates.
To update an existing installation, select its current application folder and
clear the shortcut task to keep existing shortcuts. Continue launching through
the existing profile shortcut; do not use launch_fresh_profile.ps1 for an
existing working profile.

This release adds supported management for built-in and user-defined service
categories. New categories require an explicit existing calculation type;
used categories keep their type, and archiving preserves history.

The packages contain no working database, invoice documents, login sessions,
passwords, or personal settings.

The verified previous release is available in rollback/1.0.50/.
