SmartReport 1.0.70 - Windows x64 (client only; no server change)

This update is for the existing approved user profile. Keep the existing
SmartReport-1.0.9 profile and shortcut names; do not create or select a fresh
profile. The installer contains application files only.

Object card:
- "Remove from object" removes only the selected file link, or the selected
  email and attachments imported with it. Other object links and separately
  added documents are preserved; the original email is not changed.
- The info-mail picker and full email reader can be resized and maximized.
  The message list, body and attachment list use the available space.
- Object documents remain local to this computer in the existing profile.
  They are included in backup and recovery; they do not synchronize.

The info mailbox remains a separate, read-only connection. This update does
not send mail, mark messages as read, import a mailbox automatically, or
change financial calculations.

No server deployment or server-side change is part of this release.

Keep the verified rollback installer in installer/rollback/1.0.69. Roll back
application files only; never replace newer working data with an older database.
