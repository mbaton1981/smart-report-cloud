SmartReport 1.0.53 - Windows x64

SmartReport-Setup-1.0.53.exe is the installer for the current Windows user.
SmartReport-1.0.53-build-win64.zip contains the same application files.

For an existing installation, select its current application folder and clear
the shortcut task. Keep using the existing approved-profile shortcut.
Do not run launch_fresh_profile.ps1 against an existing working profile.

Customer prices: Reports and invoicing > Other actions > Customer prices
for the selected period. The form now shows saved historical prices, missing
prices per record, and the customer hourly total (base plus OB premium).
Saving fills only missing prices; individual and closed prices stay protected.
An OB premium is not an employee salary rate. OB hours are already included
in total hours. This release does not close any working period automatically.

No working databases, original documents, credentials or user settings are
included. The previous application release is preserved in rollback/1.0.52/.
Rollback replaces application files only; do not restore an older database
over newer operations. Preserve the existing profile and incoming queue.
