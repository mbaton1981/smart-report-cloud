SmartReport 1.0.69 - Windows x64 (client only; no server change)

This update is for the existing approved user profile. Keep the existing
SmartReport-1.0.9 profile and shortcut names; do not create or select a fresh
profile. The installer contains application files only.

Object card readability:
- The card keeps its three sections: Overview, Documents and Agreements.
- Document names and email subjects receive the available table width; empty
  offer-status columns are hidden, and offer versions/statuses remain visible.
- A selected email can be read in full. Agreement text wraps and can be opened
  as a full record. Overview dates stay on one row and key values are bold.
- The info connection form is wider and its address and IMAP server fields are
  readable. Mail dates are displayed in Stockholm local time.
- No live info mailbox was configured or tested by this release.

No server deployment, email sending, automatic mailbox import, financial
calculation, or customer data change is part of this release.

Keep the verified rollback installers in installer/rollback/1.0.67 and
installer/rollback/1.0.68. Roll back application files only; never replace
newer working data with an older database.
