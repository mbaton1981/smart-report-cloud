SmartReport 1.0.52 - Windows x64

SmartReport-Setup-1.0.52.exe is the installer for the current Windows user.
SmartReport-1.0.52-build-win64.zip contains the same application files.

For an existing installation, select its current application folder and clear
the shortcut task. Keep using the existing approved-profile shortcut.
Do not run launch_fresh_profile.ps1 against an existing working profile.

This desktop release improves invoice issuer/total recognition, distinguishes
order confirmations, and matches equivalent project markings in context.
Expense object selectors support name/marking search, an archive filter, and
explicit selection. Suggestions never confirm expenses or select objects.

No working databases, original documents, credentials or user settings are
included. The previous application release is preserved in rollback/1.0.51/.
Rollback replaces application files only; do not restore an older database
over newer operations. Preserve the existing profile and incoming queue.
